# EduComm — A Comprehensive Communication and Collaboration Platform for Education

> ### ⚠️ The application lives on the [`Deployed`](https://github.com/Seifeldin02/EduComm/tree/Deployed) branch, not here.
>
> **`main` holds only the initial Vite scaffold.** For the complete project — source,
> architecture and documentation — go to
> **[the `Deployed` branch](https://github.com/Seifeldin02/EduComm/tree/Deployed)**.

EduComm is a unified academic communication platform for students and lecturers,
replacing the usual sprawl of WhatsApp, Telegram, Discord and email with one
academic-first workspace. It translates messages in real time using LibreTranslate
self-hosted in Docker, so students and staff who do not share a language can still
work together.

Built as my final year project (PSM) for the Bachelor of Computer Science (Software
Engineering) at **Universiti Teknologi Malaysia**, completed July 2025.

- **Front end (this repo, `Deployed` branch)** — React, TypeScript, Vite, Tailwind,
  Zustand, React Router, Firebase Auth
- **Backend** — [`educomm-backend`](https://github.com/Seifeldin02/educomm-backend),
  Next.js API routes over Firestore, with a WebSocket layer

Features include group and direct messaging, course topic forums, file sharing,
role-separated student and lecturer dashboards, assignments and submissions, and
PDF activity reports.
